# cumu v0.3.1 — Genre Detail Views, Album Metadata Editing & API Enhancements

This release adds dedicated genre breakdown pages, live album editing capabilities, enhanced search result structures, and overall stability improvements.

---

## Highlights & New Features

- **Genre Detail Breakdown:**
  Explore tracks, top artists, and featured albums categorized by genre with full statistical insights.

- **Album Metadata Editing:**
  Edit title, artist, release year, genre, and audiobook tags directly from the album view.

- **Enhanced Search & Dynamic Playlists:**
  Improved search endpoint returning complete playlist track listings and support for dynamic auto-generated playlists.

- **UI & Mobile Optimizations:**
  Refined UI styling additions, offline store updates, and improved mobile app compatibility.

---

## Installation Options

### Option 1: One-Line Installer (Recommended for Linux / LXC)
```bash
curl -fsSL https://raw.githubusercontent.com/Wolfiku/cumu/main/scripts/install.sh | bash
```

### Option 2: Docker Compose
```bash
git clone https://github.com/Wolfiku/cumu.git
cd cumu
docker compose up -d
```

### Option 3: Debian / Ubuntu Package (.deb)
```bash
dpkg -i cumu_0.3.1_amd64.deb
```
